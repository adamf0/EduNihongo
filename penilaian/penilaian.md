RUBRIK DAN PEDOMAN PENSKORAN
KUIS MODEL A-D
Bahan Ajar Jukugo Kanji melalui Semantic Graph
A. Tujuan Penilaian
Pedoman penskoran ini digunakan untuk menilai empat model kuis pada bahan ajar jukugo kanji. Keempat model kuis memiliki bentuk tugas dan kemampuan yang dinilai berbeda, sehingga teknik penskorannya disesuaikan dengan karakteristik masing-masing model. Seluruh hasil akhir dikonversi ke skala 0-100 agar dapat dibandingkan dan direkap secara konsisten.
Penilaian kuis menggunakan kombinasi rubrik analitik dan penskoran dikotomis yang disesuaikan dengan karakteristik respons setiap model kuis, kemudian skor dikonversi ke skala 0–100.

C. Rubrik Penilaian Kuis Model A
Model A meminta mahasiswa menyusun kata-kata yang tersedia menjadi kalimat yang tepat. Karena jawaban berupa konstruksi kalimat, penilaian tidak hanya menggunakan benar-salah, tetapi mempertimbangkan ketepatan susunan, penggunaan jukugo, partikel, dan pola kalimat.

Rumus nilai Model A:
Nilai Model A = (Jumlah skor yang diperoleh / Skor maksimum) x 100
Contoh: apabila terdapat 5 soal, skor maksimum = 5 x 4 = 20. Mahasiswa memperoleh skor 17, maka nilai = (17 / 20) x 100 = 85.
D. Pedoman Penskoran Kuis Model B
Model B meminta mahasiswa menempatkan setiap jukugo ke dalam kelompok makna yang sesuai berdasarkan semantic graph. Unit penilaian adalah setiap jukugo, bukan jumlah kelompok. Hal ini penting karena jumlah jukugo yang dikelompokkan dapat berbeda pada setiap kanji.

Rumus nilai Model B:
Nilai Model B = (Jumlah jukugo yang dikelompokkan dengan benar / Jumlah seluruh jukugo) x 100
Contoh: terdapat 8 jukugo dan 7 jukugo ditempatkan pada kelompok yang benar. Nilai = (7 / 8) x 100 = 87,5.
E. Pedoman Penskoran Kuis Model C
Model C meminta mahasiswa memilih jukugo yang paling tepat berdasarkan deskripsi makna. Karena setiap butir memiliki satu jawaban yang benar, penskoran menggunakan sistem dikotomis.

Rumus nilai Model C:
Nilai Model C = (Jumlah jawaban benar / Jumlah soal) x 100
Contoh: pada kuis yang terdiri atas 5 soal, mahasiswa menjawab 4 soal dengan benar. Nilai = (4 / 5) x 100 = 80. Jika setiap kuis terdiri atas 5 soal, satu jawaban benar setara dengan 20 poin.

J. Catatan Penggunaan
• Model A memerlukan penilaian berdasarkan rubrik 0-4 pada setiap butir karena jawaban berupa susunan kalimat.
• Model B dinilai berdasarkan ketepatan penempatan setiap jukugo. Jumlah kelompok semantic graph tidak memengaruhi skor secara langsung.
• Model C dan Model D dapat dinilai secara otomatis karena setiap soal memiliki satu jawaban benar.
• Semua model dikonversi ke skala 0-100 agar hasil penilaian memiliki satuan yang sama.
• Apabila nilai keempat model akan digabungkan menjadi satu nilai kuis, bobot antar-model sebaiknya ditetapkan secara eksplisit sesuai tujuan evaluasi dan kebijakan pembelajaran.

Dokumen ini disusun sebagai pedoman penskoran untuk empat model kuis pada bahan ajar jukugo kanji melalui semantic graph.
